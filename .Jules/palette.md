## 2026-03-02 - Touch Target Minimum Ergonomics for Tablet CAD Interfaces
**Learning:** In Jetpack Compose custom tab bars and dense CAD toolbars, icon-only buttons like overflow menus (`MoreVert`) and inline add buttons (`+`) often fall below the recommended 40-48dp touch target threshold if styled strictly with compact container sizes (e.g., 18dp/32dp). Using `defaultMinSize(minWidth = 40.dp, minHeight = 40.dp)` or standard `IconButton` wrappers maintains visual density while providing comfortable, accessible touch targets for tablet users in active CAD editing sessions.
**Action:** Always ensure interactive elements (especially icon-only buttons in dense scrollable bars) meet at least 40dp (ideally 48dp) minimum touch target dimensions without breaking horizontal scroll layout alignment.
